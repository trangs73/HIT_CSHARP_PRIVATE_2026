Họ và tên: Lê Đinh Đình Tráng

Mục tiêu học tập: - Nắm vững kiến thức cơ bản về C# và lập trình hướng đối tượng.
			- Học cách sử dụng Git và GitHub để quản lý mã nguồn.
			- Làm quen với Unity và phát triển các sản phẩm nhỏ.

Công cụ sử dụng:  - C#: ngôn ngữ lập trình.
			- Visual Studio Community.
			- .NET SDK: tạo và chạy ứng dụng C#.
			- Git và GitHub: quản lý mã nguồn.

Các khái niệm Git cơ bản: - clone: tải repo và cấu hình liên kết origin.
				  - commit: lưu các thay đổi đã chọn vào lịch sử trên máy.
				  - push: gửi commit; cần quyền ghi và đăng nhập GitHub theo hướng dẫn công cụ.
				  - pull: lấy thay đổi từ xa và tích hợp vào nhánh hiện tại. Nên commit công việc trước khi pull.
